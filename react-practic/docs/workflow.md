# Процесс обучения

Рабочий цикл для прокачки в разработке через этот проект.

## Цикл

1. **Идея** — своя, либо спросил у ИИ, что делать дальше.
2. **Разведка** — спрашиваю у ИИ, какую базу под эту идею нужно знать или подтянуть.
3. **Изучение** — читаю источники. Таймбокс: 1–2 часа. Что не влезло или посчитал ненужным — откладываю, не тащу через силу.
4. **Реализация** — отдаю задачу ИИ.
5. **Разбор** — читаю, разбираю, правлю сам. Не просто принимаю код как есть.
 Прошу оценить решение в третьем лице ("вот код разработчика, найди проблемы"), а не "я сделал вот так, норм?". Делаю это в новом чате без истории с предыдущих шагов цикла — не в том же треде, где до этого обсуждал идею и хвалил её.
6. **Деплой**.
7. Цикл повторяется.

## Засечки

Если после изучения темы всё равно спотыкаюсь об неё на практике,ошибка связанная с темой,затуп,неспособность обьяснить кусок кода и вопрос по куску кода — это идёт в засечки (`ЗАСЕЧКИ.md`, отдельно от `docs/`, туда не пишем).

- юзер задал вопрос про уже написанный код → засечка, без исключений;
- юзер написал "не понял / почему / объясни ещё раз" → засечка.

Три засечки на одну тему = не случайность, я в ней реально плаваю. В этом случае — ещё 1–1.5 часа отдельно на эту тему, сверх обычного таймбокса.

## Режимы Claude Code по этапам

- **Реализация (шаг 4)** — начинать с Plan mode: согласовать подход до того, как код написан.
- **Исполнение после утверждения плана** — Manual, не Accept/Auto. Смотрю каждый дифф перед принятием — в этом и есть обучение, Accept/Auto это трение убирают.
- **Auto mode** — только для рутины, которая уже понятна. На новых темах — избегать, он снижает число уточняющих вопросов и объяснений от ИИ.
- **Деплой** — всегда руками, отдельным подтверждением, вне зависимости от режима.
