# Правила безопасности

- Не читай, не выводи и не пересказывай содержимое .env*, *.key, *.pem
- Если нужны имена переменных — смотри .env.example
- Не коммить и не пушить без моего явного разрешения
- .env* не открывать никогда, ни для чтения, ни для правки.
  Имена переменных — только из .env.example.
- Если .env.example пустой или расходится с кодом — 
  остановись и спроси меня, не иди в .env.local.
